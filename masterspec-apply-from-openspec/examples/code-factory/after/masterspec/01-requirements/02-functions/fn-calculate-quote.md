# Функция: Расчёт суммы предложения

## Цель
Получить сумму предложения с налогом для внутреннего потребителя.

## Инициатор
- **Внешний инициатор/канал:** N/A — internal-only

## Триггер
Запрос расчёта внутренним потребителем.

## Предусловия
Базовая сумма — неотрицательное десятичное число.

## Основной поток
1. Система начисляет 20% налога и округляет итог до двух десятичных знаков, половины вверх.

## Альтернативные потоки
Нулевая базовая сумма допускается; результат проверяется AC-02.

## Исключительные потоки (ошибки, отказы)
N/A — поведение вне предусловия не определено этим контрактом.

## Результат
Внутренний потребитель получает исходную базовую сумму, налог и итоговую сумму. Налог равен итоговой сумме минус исходная базовая сумма.

## Постусловия
Расчёт не изменяет состояние системы.

## Контракт живой эксплуатации (OE)
OE: N/A — internal-only

## Критерии приёмки
- AC-01: при базовой сумме 10.03 итоговая сумма равна 12.04.
- AC-02: при базовой сумме 0 итоговая сумма равна 0.
- AC-03: при базовой сумме 10.03 результат содержит базовую сумму 10.03, налог 2.01 и итоговую сумму 12.04.
