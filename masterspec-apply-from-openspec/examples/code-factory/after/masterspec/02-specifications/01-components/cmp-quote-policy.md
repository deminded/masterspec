# Компонент: Политика расчёта предложения

## Назначение
Владеть результатом внутреннего расчёта предложения.

## Ответственность
Вычисление без побочных эффектов.

## Не делает
Доставку предложения клиенту и хранение истории.

## Возможности (capabilities)

### cap-calculate
- **Что делает:** выполняет расчёт по -> fn-calculate-quote.
- **Вход (логически):** базовая сумма в границах предусловия функции.
- **Выход (логически):** разбивка результата по разделу «Результат» -> fn-calculate-quote.
- **Используется функциями АС/ФП:** -> fn-calculate-quote.

## Зависимости
N/A — расчёт автономен.
