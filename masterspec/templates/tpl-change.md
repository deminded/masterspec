## 8. Критерии приёмки изменения

<!-- Чек-лист для закрытия change после apply-change. -->

- [ ] `masterspec/00-masterspec-index.md` перегенерирован полностью (выполняет `apply-change`, не вручную)

- [ ] Для `spec-only` проверка `check-change-scope.py` прошла; во всём change, `new/`, решениях и аудит-отчёте нет предложений по коду
- [ ] Для evolve каждый затронутый узел `01/02` имеет правку или обоснованный вердикт; известные соседи `03` отмечены в route-run как `deferred-to-implementation`

- [ ] У применённых артефактов слоёв `status: actual`; у `adr-`/`dr-` — свой статус (`proposed`/`accepted`); `updated:` = сегодня
- [ ] У всех MODIFIED-файлов обновлено поле `updated:`
