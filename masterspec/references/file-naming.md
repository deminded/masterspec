# Переносимые имена файлов и каталогов

Правило для всех создаваемых workflow файлов: артефактов, `changes/`, `.research/`,
`.work/` и отчётов. Проверяй каждый компонент имени после подстановки плейсхолдеров.
Пути к уже существующим исходникам сохраняются. ISO timestamp внутри содержимого
не используются как имена; отдельное поле `ts` в route-run следует формату ниже.

## Время в имени

`<ts>` в имени файла или каталога — **UTC в формате `YYYYMMDDTHHMMZ`**, например
`20260828T1700Z`. Поле `ts` в route-run содержит то же значение:

- `route-run-20260828T1700Z.md`;
- `.work/req-20260828T1700Z/`;
- `.work/run-20260828T1700Z-a1b2c3d4/` (суффикс уникальности).

Не подставляй ISO-строку с двоеточиями или локальное время с фиктивным `Z`.
Получение значения: Python — `datetime.now(timezone.utc).strftime("%Y%m%dT%H%MZ")`;
bash — `date -u +%Y%m%dT%H%MZ`.
Если имя занято, сохрани оба прогона: добавь `-2`, `-3` перед расширением
(для каталога — в конце имени) либо используй уникальный суффикс, как prepare_workspace.
Поле `ts` при этом остаётся без суффикса. Чужой файл/каталог не перезаписывай.

Дата без времени (`updated: YYYY-MM-DD`, архив `YYYY-MM-DD-<change-name>/`)
сохраняет прежний формат. Поля содержимого вроде `started_at` / `finished_at` в
`verify-report.md` используют ISO-8601 с двоеточиями: из них имя файла не строится.

## Компоненты имени

- Названия change и slug артефактов — kebab-case; фиксированные имена research
  (`_meta.yaml`, `_aggregate.yaml`, `<role>[-<batch-id>].yaml`) и отчётов сохраняются.
- В подставляемых `<name>`, `<role>`, `<batch-id>`, `<run-id>`, `<slug>` запрещены
  управляющие символы и `<>:"/\|?*`. `/` допустим только как разделитель пути,
  заданного workflow; входное имя не должно добавлять новые сегменты пути.
- Не используй пустой компонент, `.` / `..`, конечную точку/пробел или зарезервированное
  имя устройства Windows: `CON`, `PRN`, `AUX`, `NUL`, `COM1`–`COM9`, `LPT1`–`LPT9`
  (без учёта регистра, в том числе перед расширением). Различать имена только регистром нельзя.

## Уже существующие фабрики

Переименуй несовместимые файлы через `git mv`, затем обнови все ссылки на старый путь
в артефактах, индексах, change и отчётах. Сначала установи часовой пояс старого `ts`
и переведи момент в UTC; если пояс неизвестен — уточни его, не дописывай `Z` наугад.
В примере старое значение **уже означает UTC**:

```bash
git mv -- 'masterspec/changes/example/route-run-2026-09-25T21:28.md' 'masterspec/changes/example/route-run-20260925T2128Z.md'
rg --hidden -g '!.git/**' --fixed-strings 'route-run-2026-09-25T21:28.md' .
```

Исправь найденные ссылки и `ts` в переименованном отчёте, повтори поиск и проверь
`git diff --check` / `git diff --stat`. Если новое имя занято, используй суффикс выше.
Windows не может checkout старого пути с `:`: сделай переименование и коммит в
Linux/macOS либо WSL **на файловой системе Linux**, затем получи исправленный коммит
на Windows. Не отключай защиту путей Git ради checkout несовместимых имён.
